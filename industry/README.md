# industry/

Career material for GapWalk: resume bullets, interview prep, and learning notes.
This is not app code. Nothing in `src/`, `backend/`, or the build reads this folder.

| Folder | What goes here |
| ------ | -------------- |
| [resume/](resume/) | Resume bullets (Overleaf-ready `.tex`) and where each number comes from |
| `interview/` | Talking points, likely questions, system-design walk-throughs of GapWalk |
| `learning/` | Explanations of concepts, tools, and techniques used in the project |

## Contents

- [resume/gapwalk-bullets.tex](resume/gapwalk-bullets.tex): paste into Overleaf
- [resume/gapwalk-bullets-notes.md](resume/gapwalk-bullets-notes.md): sources for every number, what was left out and why, and data still to collect
